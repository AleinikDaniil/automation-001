# RetailPoint — Автоматизация отчётности по продажам

Python-инструмент для автоматического сбора, очистки и анализа данных о продажах из CSV-файлов различных торговых точек.

Программа объединяет данные из нескольких источников, проверяет корректность записей, рассчитывает показатели продаж и формирует единый итоговый отчёт.

## Возможности

- **Автоматический поиск файлов:** обнаружение всех CSV-файлов в указанной директории.
- **Проверка структуры:** контроль наличия обязательных колонок и корректности входных данных.
- **Очистка данных:** удаление пустых, некорректных и недопустимых значений.
- **Обработка нескольких источников:** объединение данных из разных CSV-файлов в единую таблицу.
- **Анализ продаж:** группировка данных по товарам и расчёт основных показателей.
- **Определение лидеров продаж:** поиск товара с наибольшей выручкой.
- **Расчёт общей выручки:** определение суммарного дохода компании.
- **Формирование отчёта:** автоматическое сохранение результатов в CSV.
- **Журналирование ошибок:** запись пропущенных файлов и строк с указанием причин.

## Формат входных данных

Программа принимает CSV-файлы со следующими обязательными колонками:

| Колонка | Тип данных | Описание |
|---|---|---|
| `product` | String | Название товара |
| `quantity` | Numeric | Количество проданных единиц |
| `price` | Numeric | Цена одной единицы товара |

### Пример входного файла

```csv
product,quantity,price
Laptop,2,1500
Mouse,10,25
Keyboard,5,50
Monitor,3,300
```

Допускается использование нескольких файлов с одинаковой структурой. Данные из всех корректных файлов объединяются перед проведением анализа.

## Установка и запуск

### 1. Требования

Для работы программы необходимо:

- Python версии 3.8 или выше.
- Библиотека Pandas.

### 2. Клонирование репозитория

```bash
git clone https://github.com/AleinikDaniil/automation-001.git
cd RetailPoint
```

### 3. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows:

```bash
.venv\Scripts\activate
```

Активация в Linux / macOS:

```bash
source .venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install pandas
```

### 5. Подготовка данных

Поместите CSV-файлы с данными о продажах в директорию `data/`.

### 6. Запуск программы

```bash
python main.py
```

После выполнения программы итоговый отчёт будет сохранён в директории `reports/`, а информация об ошибках — в `errors.log`.

## Правила обработки данных

Программа использует следующие правила проверки и очистки данных.

### 1. Обработка файлов

| Ситуация | Действие |
|---|---|
| Файл размером 0 байт | Пропускается |
| Файл не является корректным CSV | Пропускается |
| Ошибка кодировки | Файл пропускается |
| Отсутствует обязательная колонка | Весь файл пропускается |
| Нарушена структура отдельной строки | Строка пропускается |
| Файл не содержит записей | Пропускается |

Обязательные колонки: `product`, `quantity`, `price`.

### 2. Обработка отдельных записей

Запись исключается из расчётов, если обнаружено хотя бы одно из следующих нарушений:

| Нарушение | Пример | Причина исключения |
|---|---|---|
| Пустое значение | `Laptop,,1500` | Отсутствует количество |
| Пустое название товара | ` ,2,1500` | Название состоит из пробелов |
| Некорректное количество | `Laptop,two,1500` | Значение не является числом |
| Некорректная цена | `Laptop,2,unknown` | Значение не является числом |
| Отрицательное количество | `Laptop,-2,1500` | Количество должно быть положительным |
| Нулевое количество | `Laptop,0,1500` | Количество должно быть больше нуля |
| Отрицательная цена | `Laptop,2,-1500` | Цена должна быть положительной |
| Нулевая цена | `Laptop,2,0` | Цена должна быть больше нуля |

Все исключённые записи фиксируются в журнале ошибок с указанием исходных данных и причины пропуска.

## Формат итогового отчёта

Результат анализа сохраняется в файле:

`reports/sales_report.csv`

Отчёт содержит следующие колонки:

| Колонка | Описание |
|---|---|
| `product` | Название товара |
| `total_quantity` | Общее количество проданных единиц |
| `total_revenue` | Общая выручка от продажи товара |

Выручка рассчитывается по формуле:

```text
total_revenue = quantity * price
```

Для каждого товара рассчитывается суммарное количество проданных единиц и общая выручка по всем торговым точкам.

### Пример итогового отчёта

```csv
product,total_quantity,total_revenue
Laptop,5,7500
Keyboard,15,750
Monitor,8,2400
Mouse,30,750
ИТОГО,,11400
```

Последняя строка `ИТОГО` содержит общую выручку компании по всем товарам.

Дополнительно программа определяет товар с наибольшей общей выручкой.

## Обработка ошибок

Для обеспечения устойчивой работы программа предусматривает обработку некорректных входных данных.

Ошибки и пропущенные записи фиксируются в файле:

`errors.log`

В журнал записываются:

- Название исходного файла.
- Номер проблемной строки, если он доступен.
- Исходные значения записи, если они доступны.
- Причина исключения из обработки.

Программа стремится продолжать обработку остальных файлов и записей при обнаружении ошибок, не прерывая весь процесс без необходимости.
